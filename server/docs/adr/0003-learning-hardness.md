# ADR-0003：学习硬度 = 必修+激励，无及格无认证

- **状态**：Accepted
- **日期**：2026-05-24
- **决策者**：产品负责人（grill 访谈 Q3、Q6）
- **相关**：[PRD §5.5](../../../docs/prd-v1.md#55-课程模块apps-mobile-courseid已存在原型), [PRD §5.6](../../../docs/prd-v1.md#56-答题模块apps-mobile-quiz-tab--课程内-quiz-章节), [PRD §5.7](../../../docs/prd-v1.md#57-积分与晶升)

## 背景 (Context)

B 端培训平台的"学习硬度"决定整个产品体感。候选光谱：

- **强制 KPI 式**：总部下必修，没完成被通报扣返点
- **混合（必修+激励）**：总部下必修但有截止时间；学完攒积分晶升
- **纯激励式**：一切自愿，学了拿积分
- **纯赋能式**：完全自取所需

进一步决策点：
- 结业考是否设及格线 / 补考
- 是否做"产品认证考"作为晶升门槛
- 是否做防作弊机制
- 晶升是否与 ERP（进货价、返点）联动

## 决策 (Decision)

整体调性：**轻量激励、不施压、不挂实利**。具体：

1. **必修+激励模式**：总部可标记课程为必修课、设置截止时间；同时学习+答题+签到累积积分
2. **结业考不卡及格**：答完即"完成"，积分按准确率比例发放
3. **章节随堂测验也不卡及格**：答完即过
4. **不做防作弊**：不倒计时、不防截屏、不打乱题序，相信经销商自觉
5. **不做产品认证考**：晶升只看 `totalEarned`（累计积分），无独立认证考试节点
6. **晶升不挂 ERP**：金牌讲师等级是纯虚拟身份，不影响进货价、不送实物
7. **学习时长**不参与晶升阈值，仅作为同等级内的二级展示

## 后果 (Consequences)

### Schema 影响
- **修改** `dh_live_course` 加 `is_required`, `deadline`, `required_scope`
- **修改** `dh_live_quiz_question.type` 枚举加 `'judge'`
- **不需要**新增"考试会话""考试通过""及格判定"等实体
- `dh_live_member_points_account.total_earned` 直接驱动晶升

### 正面
- 经销商反感被考被压 → 这套调性贴合 B 端心智
- 开发量大幅压缩（无及格逻辑、无补考、无防作弊、无认证考实体）
- 晶升判定逻辑极简：`if (totalEarned >= 阈值) → 升级`

### 负面
- 缺失"考过 / 没考过"的二元张力 → 部分总部利益相关者可能觉得"太软"
- 不防作弊 → 理论上有人乱答也能拿积分（但 v1 经销商规模小、人工抽查可控）
- 没有 ERP 联动 → 晶升的实际经销商驱动力依赖运营宣传"金牌讲师光环"

### 验证指标
- v1 上线 3 个月后看必修课完成率是否 ≥70%
- 看晶升等级分布是否呈金字塔（避免人人见习的塌方场景）
